# LDK Makro (Android)

Üç sürüklenebilir ekrana dokunma hedefi ve yüzen M kontrolü kullanan Android uygulaması.

- 1: Hedef / düşman
- 2: Saldır
- 3: Konuşlandır
- Her konuşlandır dokunuşundan sonra bağımsız **45–90 saniye arasında rastgele bekleme**
- **4–8 dakika arayla** seçilen anlarda **1–5 dakika ilave rastgele mola**
- Ekranda yüzen M: Noktaları yerleştir, kaydet, başlat ve durdur
- OCR, internet bağlantısı, ekran kaydı veya hedef tanıma kullanılmaz.
- Aralıkların rastgeleliği oyunun kurallarından muafiyet veya ban koruması sağlamaz.

## Android telefonla APK indirme

**Actions → APK Olustur → yeşil tamamlanan çalışma → Artifacts → LDK-Makro-APK**. İndirilen ZIP dosyasındaki **app-debug.apk** kurulabilir geliştirme paketidir.

Kurulumdan sonra uygulamayı açıp Erişilebilirlik Hizmeti'ni etkinleştirin. Android 13'te gerekiyorsa Uygulama Bilgisi > üç nokta > Kısıtlı ayarlara izin ver. Oyunda M tuşundan üç noktayı yerleştirip kaydedin, ardından Başlat. M tuşuyla Durdur.

Sabit koordinatlar kullanılır; oyun arayüzü veya hedef yeri değişirse makro yanlış yere dokunabilir.
